      Annonces envoyées (téléphone et PC)

      Ce profil Chrome

      Un profil Chrome = un compte Vinted. Pour 4 comptes : crée 4 profils Chrome (menu profil en haut à droite → « Ajouter »), installe l'extension dans chacun, connecte-toi à Vinted avec le bon compte dans chaque profil, puis colle le même code de connexion (Réglages). Laisse les 4 fenêtres ouvertes sur le PC : chaque profil traite les annonces de son compte.

      Comptes déclarés dans le relais

      1. Relais GitHub (base de données téléphone ⇄ PC)

      Dépôt GitHub privé + token « fine-grained » limité à ce dépôt avec la permission Contents : Read and write. Les photos y transitent puis sont supprimées une fois le brouillon créé.

      2. Reconnaissance par IA (catégorie, marque, taille, couleur…)

      Avec une clé, l'extension reconnaît l'article sur les photos : tu n'as plus que le prix à donner. Gemini a une offre gratuite (clé sur Google AI Studio). Sans clé : mode gratuit (couleur + lecture des étiquettes + catégorie recommandée par Vinted).

      4. Connecter les autres profils et le téléphone

      Le code contient le token GitHub (et la clé IA) : traite-le comme un mot de passe.

      Scanne le QR avec l'appareil photo du téléphone : le dashboard s'ouvre déjà connecté.

      5. Entretien du relais

      Les photos supprimées restent dans l'historique Git. Si le dépôt grossit trop, compacte l'historique (à faire quand aucune annonce n'est en cours d'envoi).
