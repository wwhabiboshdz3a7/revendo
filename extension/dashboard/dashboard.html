      Ajouter un compte

      Pour 4 comptes : 4 profils Chrome, ouverts en même temps sur le PC

      1. 1Crée un profil Chrome (menu profil en haut à droite → « Ajouter »).
      2. 2Installe l'extension Revendo dans ce profil et connecte-toi à Vinted avec le bon compte.
      3. 3Colle le code de connexion (Réglages → Connexion) : relais et IA sont configurés d'un coup.
      4. 4Laisse la fenêtre ouverte : ce profil traitera les annonces de son compte.

      Réglages

      Relais, reconnaissance et robot de ce profil Chrome

      Relais GitHub

      Base de données entre le téléphone et ce PC. Token « fine-grained » limité à ce dépôt, permission Contents : Read and write.

      Les photos transitent par le dépôt le temps du traitement, puis sont supprimées une fois le brouillon créé.

      Reconnaissance par IA

      Catégorie, marque, taille, couleur, matière : il ne reste que le prix à donner.

      Recommandé : une clé Gemini gratuite. Sans IA, le mode gratuit (couleur + lecture des étiquettes) reconnaît mal la marque et la catégorie. Avec Gemini, l'étiquette est lue et l'article identifié. Clé gratuite sur Google AI Studio.
